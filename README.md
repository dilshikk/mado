# MADO Tashkent

Сайт сети турецких ресторанов MADO в Ташкенте.

- Стек: Vite + React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui
- Роутинг: react-router-dom 7
- Контент страниц: `src/content/*` (легко переносится в PostgreSQL)

## Запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```
